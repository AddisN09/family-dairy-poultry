# Family Farm & Veterinary Portfolio

A responsive frontend website for a family poultry and dairy business, combined with a professional portfolio for a veterinarian specializing in poultry management and cattle medicine.

## Version

**v1.0.0 — Frontend**

## Website Sections

- **Home** — Introduction to the family farm and veterinary services
- **About** — Family business and veterinarian profile
- **Poultry** — Poultry products and information
- **Dairy** — Dairy products and information
- **Veterinary Services** — Poultry management and cattle medicine services
- **Diary** — Farm updates, articles, and animal-health information
- **Contact** — Contact and business information

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## v1.0.0 Scope

Version 1.0.0 is the initial frontend release.

It includes:

- Responsive website layout
- Navigation between all main pages
- Family farm information
- Poultry products section
- Dairy products section
- Veterinary services section
- Professional veterinarian portfolio
- Farm diary section
- Contact page
- Responsive design for desktop and mobile
- Static deployment through GitHub Pages
